# Xcode kısayolları

En çok işe yarayanlar başta. İlk hafta ⭐ işaretlileri ezberle, gerisi zamanla gelir.

> Sembol rehberi: ⌘ Command · ⌥ Option · ⌃ Control · ⇧ Shift · ↩ Return
> Bir kısayol beklendiği gibi çalışmazsa: Xcode › Settings › **Key Bindings**'te komutun adını ara. Oradan istediğin kısayolu da atayabilirsin.
> Menüyü hatırlamıyorsan: ⌘⇧A (**Quick Actions**) aç ve komutun adını yaz.

## Gezinme
| Kısayol | Ne yapar |
|---|---|
| ⭐ ⌘⇧O | **Open Quickly**: dosya, tip, fonksiyon adına göre anında aç |
| ⭐ ⌘⇧A | **Quick Actions**: menüdeki herhangi bir komutu adıyla bul ve çalıştır |
| ⭐ ⌃⌘J veya ⌘-tık | Tanıma git (jump to definition) |
| ⭐ ⌥-tık | Quick Help: sembolün dokümantasyonu |
| ⌃⌘← / ⌃⌘→ | Geri / ileri (tarayıcıdaki gibi) |
| ⌘⇧J | Açık dosyayı Project Navigator'da göster |
| ⌃6 | Dosyadaki fonksiyon ve `MARK` listesi; açıldıktan sonra yazarak filtrele |
| ⌘L | Satıra git |
| ⌘1 … ⌘9 | Navigator sekmeleri (⌘1 Project, ⌘4 Find, ⌘5 Issue…) |
| ⌘0 | Sol paneli (navigator) aç/kapa |
| ⌥⌘0 | Sağ paneli (inspector) aç/kapa |
| ⌘⇧Y | Alt paneli (debug area) aç/kapa |
| ⌘⇧C | Konsola odaklan |
| ⌘T / ⌘W | Yeni sekme / sekmeyi kapat |

## Arama
| Kısayol | Ne yapar |
|---|---|
| ⌘F | Dosyada bul |
| ⌥⌘F | Dosyada bul ve değiştir |
| ⭐ ⌘⇧F | Projede bul |
| ⌥⌘⇧F | Projede bul ve değiştir |
| ⌘G / ⌘⇧G | Sonraki / önceki eşleşme |

## Düzenleme
| Kısayol | Ne yapar |
|---|---|
| ⭐ ⌃I | Seçili kodu yeniden hizala (re-indent) |
| ⭐ ⌘/ | Satırı yorum yap / yorumu kaldır |
| ⭐ ⌃⌘E | Edit All in Scope: değişkeni bulunduğu kapsamda her yerde birlikte düzenle |
| ⌥⌘[ / ⌥⌘] | Satırı yukarı / aşağı taşı |
| ⌘[ / ⌘] | Girintiyi azalt / artır |
| ⌥⌘/ | Fonksiyonun üstüne `///` doküman şablonu ekle |
| ⌥⌘← / ⌥⌘→ | Bloğu katla / aç |
| ⌥⌘⇧← / ⌥⌘⇧→ | Tüm blokları katla / aç |
| ⌃⇧-tık | Çoklu imleç ekle |
| ⌥-sürükle | Sütun (dikdörtgen) seçimi |
| ⭐ ⌘⇧L | **Library**: snippet'ler, SF Symbols, renkler, view ve modifier'lar |
| ⎋ (Esc) | Otomatik tamamlamayı elle aç |
| Sağ tık › Refactor › Rename | Sembolü tüm projede güvenle yeniden adlandır |

## Build, run, test
| Kısayol | Ne yapar |
|---|---|
| ⭐ ⌘B | Build |
| ⭐ ⌘R | Run |
| ⭐ ⌘U | Tüm testleri çalıştır |
| ⭐ ⌘. | Durdur |
| ⌘⇧K | Clean Build Folder: tuhaf build hatalarında ilk çare |
| ⌃⌘R | Build etmeden çalıştır (son build'i kullanır) |
| ⌘I | Profile: Instruments ile çalıştır |
| ⌘< | Edit Scheme: ortam değişkenleri, argümanlar, diagnostics |
| ⌘⇧2 | Devices and Simulators penceresi |
| ⌘⇧0 | Developer Documentation penceresi |

## Debug
| Kısayol | Ne yapar |
|---|---|
| ⭐ ⌘\ | Bulunduğun satıra breakpoint ekle / kaldır |
| ⌘Y | Tüm breakpoint'leri aktif / pasif yap |
| ⌃⌘Y | Devam et / duraklat |
| F6 | Step over: satırı çalıştır, içine girme |
| F7 | Step into: fonksiyonun içine gir |
| F8 | Step out: fonksiyondan çık |

> MacBook'ta F tuşları için `fn` gerekebilir. Sistem Ayarları › Klavye'den F tuşlarını standart yapabilirsin.
