# Kaynaklar

Seçilmiş, güvenilir kaynaklar. Her modülün README'sinde o modüle özel linkler de var. Bir konuda takıldığında sıra: **Apple dokümanı → bu listedeki uzman blogları → Swift Forums**.

## Apple (birincil kaynak)

| Kaynak | Ne için |
|---|---|
| [The Swift Programming Language](https://docs.swift.org/swift-book/) | Dilin resmi kitabı. 01 ve 02 modüllerinin referansı |
| [Apple Developer Documentation](https://developer.apple.com/documentation/) | Tüm framework'lerin API referansı |
| [SwiftUI Tutorials](https://developer.apple.com/tutorials/swiftui) | Apple'ın resmi, adım adım SwiftUI eğitimleri |
| [Develop in Swift Tutorials](https://developer.apple.com/tutorials/develop-in-swift) | Uçtan uca uygulama geliştirme eğitimleri |
| [WWDC videoları](https://developer.apple.com/videos/) | Her yeni API'nin "neden"i burada anlatılır. Modül README'lerinde ilgili oturumlar linkli |
| [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) | Tasarım kuralları. "Bu iOS'ta nasıl görünmeli?" sorusunun cevabı |
| [App Store Review Guidelines](https://developer.apple.com/app-store/review/guidelines/) | Uygulamanın reddedilmemesi için kurallar (12. modül) |
| [Apple Developer Forums](https://developer.apple.com/forums/) | Apple mühendislerinin de cevap verdiği forum |

## Bu listeye ekleme kuralı
Bir kaynak buraya ancak (1) güncelse (Swift 5.9+ / iOS 17+), (2) yazarı tanınıyorsa ve (3) bir drill'de gerçekten işe yaradıysa eklenir.
